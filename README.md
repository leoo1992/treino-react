# Treino React

Repositório de prática com React 18 e Create React App para experimentar componentes, estado e composição de interfaces.

## Stack
- React 18
- JavaScript
- Create React App
- React Testing Library

## Como executar

```bash
npm install
npm start
```

Acesse http://localhost:3000. Testes: `npm test`; build: `npm run build`.
